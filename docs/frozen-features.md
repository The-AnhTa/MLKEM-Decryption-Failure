# Frozen scalable feature families

These feature definitions were fixed after E0 and before inspecting E1-E5.

## Public-key features

- `at_norm_pair`: squared centered coefficient norms `(||A||^2, ||t||^2)`.
- `at_pair_histogram`: counts of centered pairs `(A[i,j,r], t[i,r])`.
- `at_correlations`: correlations
  `sum(i,j,r) center(A[i,j,r])*center(t[i,(r+shift) mod n])` for the first
  `min(4,n)` shifts.
- `at_projections`: four fixed integer linear forms over flattened `(A,t)`:
  unit weights, periodic weights `1..5`, alternating signs, and periodic weights
  generated by `((3*i+1) mod 7)-3`.

The existing `t_norm2`, `t_histogram`, and `t_autocorrelation` features remain
unchanged.

## Ciphertext features

- `hist_u`, `hist_v`: separate compression-symbol histograms.
- `extreme_symbols`: counts of symbols `0` and `2^d-1` in each component.
- `entropy_1024`: empirical symbol entropies rounded to 1/1024 bit.
- `decompressed_norms`: squared centered norms of decompressed `u` and `v`.
- `joint_uv_histogram`: counts of aligned `(u[j,i],v[i])` symbol pairs.

All feature families are deterministic and have descriptions independent of
the parameter values. No thresholds are tuned on E1-E5.
